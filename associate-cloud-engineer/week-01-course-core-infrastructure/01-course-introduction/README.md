# Module 1: Course Introduction

What the course covers, who it is for, and its seven learning objectives.

## Section 1.1 Course Introduction

Video: [Course Introduction](https://youtu.be/xVmam01f4Fw) (2m 1s)

Key concepts:

- **Course goal:** an overview of Google Cloud, delivered through videos, quizzes and hands-on labs. You learn the value of Google Cloud and how cloud solutions factor into business strategies.
- **Google Cloud offering categories:**
  - Compute
  - Storage
  - Big data
  - Machine learning
  - Application services for web, mobile, analytics and back-end solutions
- **Target audience:**
  - Solutions developers
  - Systems operations professionals
  - Solution architects planning to deploy applications and create application environments on Google Cloud
  - Business decision makers evaluating Google Cloud
- **Level:** fundamentals. Some content is aimed at learners who are entirely new to cloud technologies.
- **Prerequisites:** none. It helps to be familiar with application development, Linux operating systems, systems operations, and data analytics or machine learning.
- **Seven learning objectives.** By the end of the course you should be able to:
  1. Identify the purpose and value of Google Cloud products and services.
  2. Define how infrastructure is organized and controlled in Google Cloud.
  3. Explain how to create a basic infrastructure in Google Cloud.
  4. Select and use Google Cloud storage options.
  5. Describe the purpose and value of Google Kubernetes Engine.
  6. Identify the use cases for serverless Google Cloud services.
  7. Combine Google Cloud knowledge with prompt engineering to improve Gemini responses.
