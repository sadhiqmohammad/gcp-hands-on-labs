# gcp-hands-on-labs

Step-by-step labs and notes from my Google Cloud certification prep. Each guide has the gcloud commands, console paths and troubleshooting for one lab or skill badge.

## Certifications

| Cert | Status | Folder |
|---|---|---|
| Associate Cloud Engineer (ACE) | In progress, ACE15 cohort (Nov to Dec 2026) | [associate-cloud-engineer/](associate-cloud-engineer/) |
| Professional Cloud Architect | Planned | — |

## Layout

- `associate-cloud-engineer/`: one folder per cohort week, named `week-NN-lab-<topic>` for skill badge labs or `week-NN-course-<topic>` for course module notes, plus side labs and exam notes
- `shared/`: material reused across certs, such as a gcloud cheat sheet

Where a lab is relevant to more than one cert, the full guide lives in the cert where I first did it and the others link to it.
